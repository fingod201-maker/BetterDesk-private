# BetterDesk — Android Unattended Access Setup
#
# 1. Download the APK from https://zoom.telcom.stream/download/android
# 2. Install the APK on the device
# 3. Open the BetterDesk Agent app
# 4. Navigate to: Settings → Security → Permanent password
# 5. Set a strong permanent password (operators use this, no approval needed)
# 6. Enable "Unattended access" toggle (skip consent popup for operators)
# 7. The device will auto-register with panel.telcom.stream
#
# From the admin console (https://panel.telcom.stream):
#   - Select the Android device from the online list
#   - Click "Remote" → enter the permanent password
#   - Remote control session starts immediately (no user approval on device)
