Installation help

Most installs finish in under a minute. Pick your platform for the exact steps.

WINWindows
  1. Open the downloaded .exe from your Downloads folder.
  2. If SmartScreen appears, choose More info → Run anyway.
  3. Finish the wizard. The client launches and connects automatically.
Download for Windows
MACmacOS
  1. Open the downloaded .dmg.
  2. Drag the app into Applications.
  3. Launch it and approve Screen Recording when macOS asks.
Download for macOS
LNXLinux
  1. Download the .AppImage (no install needed) or the .deb / .rpm for your distribution.
  2. AppImage: right-click → Properties → Permissions → Allow executing file, then open it.
  3. Debian/Ubuntu: sudo apt install ./zoom-private*.deb
Download for Linux
ANDAndroid
  1. If Chrome warns about the file type, tap Download anyway.
  2. Open the downloaded .apk and confirm Install.
  3. Allow Install unknown apps for your browser if prompted, then open the app.
Download for Android
iOSiPhone / iPad
  1. Open the meeting link from your invitation.
  2. Install the app from the App Store if your admin provides it.
  3. Sign in to connect to your team.
On iOS, the meeting link is all you need. No direct download is required.
